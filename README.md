## 📌 Executive Project Overview & Business Problem

In two-sided ride-hailing marketplaces, **driver supply deficit** is a critical operational bottleneck. When drivers encounter low-profitability requests due to traffic congestion, long deadhead miles, or high platform commissions, they frequently reject or cancel rides. This directly leads to:
* **High Customer Churn Rates** due to exponentially increased waiting times.
* **Severe Revenue Deficits** for the platform during critical peak-demand windows.

### 💡 The Solution:
This project engineers a robust data pipeline that ingests raw ride-sharing logs, calculates real-time net hourly earnings for drivers, trains a **Random Forest Machine Learning Classifier** to predict high-cancellation risk segments, and serves live dynamic pricing recommendations via an interactive production-grade **Streamlit Dashboard**.

### 📊 Dataset Source
> **Original Data:** [Uber and Lyft Dataset Boston, MA](https://www.kaggle.com/datasets/brllrb/uber-and-lyft-dataset-boston-ma) from Kaggle  
> *This dataset contains over 600,000 ride-hailing transactions across Boston metropolitan area including pickup zones, trip distances, timestamps, surge multipliers, and pricing details.*

## ⚙️ Core Technical Pipeline Architecture

The project architecture is structured into 5 isolated modular frameworks to ensure high maintainability and clean code separation:

> **[Raw Ingestion] ➔ [Data Cleaning] ➔ [Feature Engineering] ➔ [Random Forest Modeling] ➔ [Streamlit UI Deployment]**

1. **Data Cleaning & Pipeline Integrity:** Dropped structural anomalies, treated heavy computational outliers, and handled missing values across 600,000+ transactional ride records to prevent data leakage.
2. **Advanced Feature Engineering:** Formulated complex domain-specific metrics including `driver_net_per_hour` (incorporating a strict 20% platform commission deduction rule) and mapped operational risk thresholds (`low_pay_flag`).
3. **Exploratory Data Analysis (EDA):** Leveraged Seaborn and Matplotlib to map geospatial and temporal trends to isolate supply bottlenecks.
4. **Predictive Modeling:** Deployed an optimized Random Forest Classifier using Scikit-Learn to evaluate predictive safety signals for drivers.
5. **UI Serving Layer:** Developed an interactive dynamic simulation control panel using Streamlit to present actionable solutions to executives.

## 🤖 Machine Learning Framework & Modeling

A **Random Forest Classifier** was trained to evaluate and classify whether a newly requested trip profile poses a severe cancellation risk (`low_pay_flag = 1`) based on independent temporal and spatial variables.

* **Features Evaluated (X):** `distance`, `surge_multiplier`, `hour_of_day`, `day_of_week`, `is_weekend`
* **Target Predictor (y):** `low_pay_flag` (1 if estimated net rate drops below standard hourly baseline, else 0)
